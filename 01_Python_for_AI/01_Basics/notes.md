# Python Basics

## Variables

A variable is used to store a value.

Example:

name = "Anjana"
age = 25

## Data Types

Common Python data types:

- str
- int
- float
- bool

## Type Conversion

int()
float()
str()

## Input

input() is used to take input from the user.

Important:
input() returns a string by default.
